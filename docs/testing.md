# Testing strategy

- Unit tests cover token entropy/hashes, Origin/CSRF, permission matrix, Cognito device-SRP vectors and device administration, lifecycle dates, rank fusion, evidence grounding, privacy and role-safety detection across the supported church-volunteer taxonomy, explicit non-evidence cases, non-removable caution enforcement, general-caution search caps, log sanitization, and migration parsing.
- PostgreSQL integration tests run real migrations against PostgreSQL 17 + pgvector and cover database invariants, the magic-link/profile approval API path, trusted-browser enrollment/use/expiry/tampering/subject mismatch/revocation, lifecycle reminders/staleness/purge, search inputs, and immediate deletion.
- Playwright covers accessible landing/disclosure, a complete Mailpit-backed member magic-link/interview/approval/update/deletion workflow, a complete fake-auth staff sign-in/search/profile/sign-out workflow, token fragment removal, pending-interview resume after refresh and a new magic link, no browser persistence, inert untrusted content, and rejection of non-JSON edge responses. `pnpm test:smoke` selects the two complete local workflows. Axe runs on public and staff-facing pages.
- Deterministic AI evaluations cover balanced branching, established-fact memory across longer conversations, stale-note removal, repeated-question suppression, “already answered” and user-directed wrap-up controls, optional follow-ups, interview completeness, post-proposal additions, conversational deletion routing, discovery breadth, boundaries, prohibited-data redirection, private-health omission, member-stated role exclusions, self-reported caveats, evidence grounding, and prompt injection. Live Bedrock evaluation is manual and fictional-only.
- Terraform validation initializes bootstrap/dev/prod without a backend. Edge-routing unit tests ensure only browser routes receive the SPA fallback and legacy-host API requests receive JSON errors. After each deploy and CloudFront invalidation, `pnpm test:smoke:deployment` checks the canonical browser routes, configuration, magic-link acceptance through the SES simulator, prompt staff-login rejection, API 404 preservation, and legacy-host handling. Repository scanning rejects common credentials, forbidden browser stores/raw HTML, and likely body logging.

The full command set is in `README.md`. Any new authorization, lifecycle state, data store, prompt, or deletion path needs positive and negative tests. Never use real people, addresses, interview text, or production tokens in fixtures or snapshots.
